Getting Started

To run the project locally:

Clone the repository
git clone https://github.com/fumbwejohnny-jfk/bootdev-static-site.git
Navigate into the project folder
cd bootdev-static-site
Open index.html in your browser

You can also use a local development server such as:

python -m http.server

Then visit:

http://localhost:8000
Deployment

This project is deployed using GitHub Pages.

To deploy updates:

Push changes to the main branch
GitHub Pages will automatically rebuild and publish the site
